# 초과근무 · 알림 친구

초과근무 시간을 대화로 등록하고, 한 시간마다 인사랑 확인을 챙기는 Windows 개인 알림 앱입니다. API 키와 인터넷 연결 없이 사용할 수 있습니다.

## 설치와 사용

1. [GitHub v1.0.0 릴리즈](https://github.com/cybereun/overtime-agent/releases/tag/v1.0.0) 또는 `배포/Overtime-Agent-Setup-1.0.0.exe`를 실행하고 설치합니다.
2. 첫 실행에서 Windows 로그인 시 자동 시작 여부를 선택합니다.
3. `오늘 오후 6시부터 9시까지`처럼 입력하고, 해석한 시간을 확인한 뒤 **등록**합니다.
4. 18:30·19:30·20:30에 작은 창이 표시됩니다. 인사랑에서 직접 처리한 뒤 **확인 완료**를 누릅니다.
5. 처리하지 못한 구간은 **사유 남기기**로 기록합니다. 완료도 사유도 없는 구간은 다음 날 오전 9시에 다시 알려줍니다.

창의 X 버튼은 트레이로 숨깁니다. 트레이 아이콘 클릭으로 다시 열며, 트레이 메뉴 **완전히 종료**로 종료합니다. 앱이 완전히 종료되었거나 PC가 꺼져 있거나 잠들어 있는 동안에는 알림을 표시할 수 없습니다. 다시 실행하거나 절전에서 돌아오면 누락을 하나의 요약으로 안내합니다.

**카카오톡 전송 앱이 아닙니다.** 카톡처럼 독립적인 작은 Windows 창을 띄웁니다. 인사랑 입력과 실제 근무기록 확인은 사용자가 직접 처리합니다.

## 대화 예시

- `오늘 18시부터 21시까지`
- `내일 오전 6~9시, 18~22시`
- `2026-10-09 18:00~21:00`
- `오늘 저녁 7시에 식사 30분 제외`
- `오늘 종료 시간을 22시로 바꿔`
- `내일 알림 취소`
- `다음 날 확인 알림을 오전 10시로 바꿔`
- `오늘 23시부터 다음 날 오전 2시까지`

`6~9시`처럼 오전·오후가 모호하면 선택지를 표시합니다. `06:00~09:00`은 24시간제로 해석합니다. **등록** 전에는 저장하지 않습니다. 복수 구간은 합쳐 등록하며, 수정 화면에서는 전체 구간을 대체합니다. 수정 화면의 제외 시간 초기화 안내를 확인해 주세요.

## 알림 규칙

- 제외 시간을 제거하고, 이어지는 근무 구간을 한 시간씩 나눕니다. 마지막 부분 구간도 중간 시각에 알립니다.
- 팝업은 키보드 포커스를 빼앗지 않습니다. 소리는 한 번 재생하고 30초 뒤 자동으로 숨깁니다.
- **10분 뒤**는 해당 구간의 알림만 미룹니다. **닫기**는 완료로 기록하지 않습니다.
- 다음 날은 주말을 포함한 달력상 다음 날입니다. 자정 넘김 구간은 각 확인 구간이 시작한 날짜 기준으로 다음 날 확인합니다.
- 시간대는 한국(UTC+9)입니다. PC 시계가 정확해야 합니다.
- 설정에서 다음 날 시각·소리·로그인 자동 실행을 변경하거나 알림창을 테스트할 수 있습니다.

## 데이터와 삭제

기록은 `%APPDATA%\초과근무\overtime.json`에 저장됩니다. `.bak`은 이전 저장 백업이며, 읽을 수 없는 원본은 `.invalid-시각` 파일로 보존합니다. 앱 제거 시 개인 기록은 유지합니다. 완전 삭제가 필요하면 앱 종료 후 해당 앱 데이터 폴더를 직접 삭제하세요.

## 개발

로컬 개발 폴더는 `N:\codex-L\overtime-agent`이며, Y: 폴더는 소스와 설치 파일 보관용입니다. 개발할 때는 소스를 로컬 디스크에 복사하고 의존성을 설치하세요.

```powershell
npm ci
npm run dev
npm test
npm run build
npm run test:desktop
npm run package
```

`npm run preview`는 화면 미리보기입니다. 브라우저에서는 실제 설정과 알림을 실행하지 않습니다. 데스크톱 검증은 `test-results/desktop-data`의 격리된 데이터를 사용하고 실제 사용자 기록을 변경하지 않습니다.

기술: Electron 44.5.1 / React / TypeScript / Vite / Vitest / Zod / electron-builder.

## MVP의 범위

계정·클라우드 동기화·실제 LLM·인사랑 자동 처리는 포함하지 않습니다. GitHub Releases 자동 업데이트를 지원하며, 새 버전 팝업에서 다운로드와 설치 후 재실행을 선택합니다. 설치 파일은 코드 서명 인증서를 적용하지 않은 MVP 빌드입니다. 다음 릴리즈 업로드 방법은 [릴리즈 안내](docs/releases.md)를 참고하세요.
