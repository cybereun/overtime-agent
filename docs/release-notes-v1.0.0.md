# 초과근무 v1.0.0

대화로 시간을 등록하면 한 시간마다 나이스 확인을 챙기는 Windows 알림 앱입니다.

- 연보라색 시계 캐릭터와 채팅창, 한국어 날짜·시간 설정
- 복수 구간, 식사 시간 제외, 자정 넘김, 수정·취소
- 작은 알림창, 소리 한 번, 확인 완료·10분 뒤·닫기
- 다음 날 미확인 구간 안내와 사유 기록
- 트레이 상주, 로그인 자동 시작 선택, 재시작·절전 복귀 복구
- GitHub Releases 업데이트 확인, 다운로드 팝업, 설치 후 자동 재실행

Windows x64 설치: **Overtime-Agent-Setup-1.0.0.exe**

`latest.yml`과 `.blockmap`은 앱 자동 업데이트용 파일입니다. 사용자는 설치 파일만 실행하면 됩니다.

나이스 처리는 사용자가 직접 수행하고 앱에 완료를 기록합니다. 근무 기록은 사용자 PC에 보관합니다. 코드 서명 인증서를 적용하지 않은 MVP 빌드입니다.
