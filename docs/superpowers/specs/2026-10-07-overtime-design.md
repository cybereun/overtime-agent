# 초과근무 MVP 승인 사양

Windows Electron + React + TypeScript 설치 앱. 연보라색 시계 캐릭터 채팅 UI.
API 없이 한국어 날짜/시간/제외/변경/취소 명령을 해석하고 저장 전 확인한다.
근무 시작부터 한 시간씩 분할, 각 구간 중간에 알림. 마지막 부분 구간도 중간.
제외 구간을 먼저 제거하고 중복을 합침. 자정 넘김 지원, 한국 시간 기준.
오른쪽 아래 작은 창, 포커스 유지, 소리 1회, 완료/10분 뒤/닫기, 30초 자동 숨김.
다음 달력일 오전 9시 전날 미완료 및 사유 없는 구간만 한 번 요약. 시각 변경 가능.
창 닫기는 트레이 숨김, 명시적 종료만 종료. 사용자 앱 데이터 폴더에 저장.
시작/절전 복귀 시 지난 알림은 하나의 누락 요약으로 복구. 발송 이력 영구 저장.
사용자가 나이스을 직접 처리하고 완료 기록. 외부 연동/LLM/계정/클라우드 제외.
로그인 자동 실행 선택, 실제 설치 및 알림 검증, Y:에 소스와 설치 파일 제공.
